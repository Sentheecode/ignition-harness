## Intentionally not used as Catalyst or official API evidence

- Third-party community MCP servers (for example PyPI/GitHub projects named `ignition-mcp-server`). Their tool names are not Inductive Automation Catalyst built-in tools.
- Search-engine summaries that conflated the REST header `X-Ignition-API-Token` with the inbound Catalyst MCP header. The Catalyst Agent page does not name that header for MCP.
